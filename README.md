# Repositions Agent

**CLI-based Portfolio Management System for Aerospace Supplier Transitions**

Repositions Agent is an intelligent, cross-functional chief of staff tool designed to manage supplier transition projects for aerospace manufacturing. It automates project prioritization, risk assessment, and supplier change coordination by integrating with enterprise data sources (Excel trackers and the ISC Agent) to provide real-time portfolio visibility.

## Features

### Core Capabilities

- **Excel-Based Project Loading** — Loads project data from SIMS sheet in Excel trackers (`.xlsm` format), including project names, part numbers, milestones, and baseline dates.
- **Deduplication** — Automatically detects and removes duplicate part numbers when loading from Excel, ensuring each part is tracked once.
- **ISC Agent Integration** — Queries the ISC Agent (Internal Supply Chain planning tool) via Selenium browser automation to enrich projects with real line-down dates and revenue impact data.
- **CSV Processing** — Processes downloaded CSV files from ISC Agent for offline enrichment when browser automation is not available.
- **Priority Scoring** — Calculates risk scores based on urgency (days to line-down), financial impact (daily revenue), overdue milestones, and cascade risk across dependent projects.
- **Milestone Tracking** — Tracks baseline dates, current ECDs (Estimated Completion Dates), and actual completion dates for each project milestone.
- **Risk Dashboard** — Displays a ranked list of projects by priority score, showing line-down dates, revenue impact, and overdue milestone counts.
- **Interactive CLI** — Command-driven interface for drilling into projects, viewing action items, and managing the portfolio.

### ISC Agent Enrichment

The ISC Agent integration is the core differentiator of this tool. It automates the process of gathering supply chain data that was previously manual:

1. **Selenium Browser Automation** — Launches Chrome, navigates to the ISC Agent chat UI, and sends part number queries.
2. **CSV Download Detection** — Monitors the download directory for CSV files generated by the ISC Agent response.
3. **Data Parsing** — Extracts line-down dates, revenue impact, open PO quantities, and customer names from CSV data.
4. **Part Aggregation** — Aggregates multiple orders per part number (summing revenue, keeping earliest line-down date).
5. **Project Enrichment** — Updates project records with real supply chain data for accurate prioritization.

## Configuration

### Excel Tracker Path

Edit `config/settings.py` to point to your Excel tracker file:

```python
EXCEL_PATH = "C:/path/to/your/Simplified IMS Template.xlsm"
```

The Excel file must contain a **SIMS** sheet with the following columns:
- Project Name, AID, Part Number, Run Out Date, Critical Part?, Simplified IMS
- Milestone columns: `[Milestone Name] Baseline ECD`, `[Milestone Name] Current ECD (CECD)`, `[Milestone Name] Actual Completion Date (ACD)`

### ISC Agent URL

```python
ISC_AGENT_URL = "https://planning.honeywell.com/ISCAgent/"
```

### SSL Verification

For corporate environments with self-signed certificates:

```python
ISC_VERIFY_SSL = False
```

## Usage

### Interactive Dashboard

```bash
python main.py
```

This will:
1. Load projects from Excel
2. Launch Chrome to query ISC Agent (press Enter to proceed)
3. Enrich projects with line-down dates and revenue data
4. Calculate priority scores
5. Display the risk dashboard

If you have a CSV file downloaded from the ISC Agent:

```bash
python scripts/process_isc_csv.py "C:\Users\YourName\Downloads\query_result.csv"
```

This processes the CSV independently without launching a browser.

## ISC Agent Integration

### How It Works

The ISC Agent is a **chat-based AI web application** (not a REST API) hosted on corporate IIS with Windows Integrated Authentication. Integration requires browser automation:

1. **Browser Launch** — Selenium opens Chrome with download directory preferences
2. **Navigation** — Navigates to the ISC Agent URL (assumes user is already logged in)
3. **Query Construction** — Formats part numbers into a chat query requesting line-down dates and revenue data
4. **Query Submission** — Uses JavaScript to set input field value (avoids triggering early sends on newlines)
5. **Response Detection** — Monitors chat messages for AI response using CSS selectors (`.message.assistant .message-body`)
6. **Stability Tracking** — Waits for 30 seconds of no response growth to ensure the AI has finished "thinking"
7. **CSV Detection** — Checks download directory for CSV files generated by the ISC Agent
8. **Data Parsing** — Extracts structured data from CSV (Part, RequestedDeliveryDate, OpenValueUSD, etc.)

### Authentication

The ISC Agent uses **Windows Integrated Authentication (NTLM)**. Since Selenium automates the browser, it uses the user's existing Windows session — no credential storage or prompts required.

**Important**: Ensure you are logged into Chrome before running `python main.py`.

## Priority Scoring

The priority algorithm calculates a composite risk score for each project:

```
Priority Score = Urgency + Financial Impact + Overdue Milestones + Cascade Risk
```

### Components

| Component | Calculation | Weight |
|-----------|-------------|--------|
| **Urgency** | `max(0, 90 - days_to_line_down)` | 1.0x |
| **Financial Impact** | `revenue_impact_daily / 1000` | 1.0x |
| **Overdue Milestones** | Count of delayed milestones | 5.0x per milestone |
| **Cascade Risk** | Dependent projects at risk | 10.0x per dependent |

### Priority Labels

| Score Range | Label |
|-------------|-------|
| 0-20 | LOW |
| 21-50 | MEDIUM |
| 51-80 | HIGH |
| 81+ | CRITICAL |

## Dashboard

The dashboard displays projects ranked by priority score, showing:

- **Status Icon** — `[OK]` On Track, `[!!]` At Risk, `[XX]` Delayed
- **Project Name** — Supplier transition project name
- **Part Number** — Unique identifier for the part
- **Priority Label** — LOW / MEDIUM / HIGH / CRITICAL
- **Priority Score** — Numeric risk score
- **Line-Down Date** — When the part goes end-of-life (from ISC Agent)
- **Days Remaining** — Days until line-down
- **Daily Revenue** — Revenue at risk per day (from ISC Agent)
- **Overdue Milestones** — Count of delayed milestones

## Development Notes

### Windows Console Compatibility

All status icons use ASCII-safe text (`[OK]`, `[!!]`, `[XX]`) to avoid `UnicodeEncodeError` on Windows cp1252 console encoding.

### Part Number Formats

The system supports multiple part number formats:
- **Honeywell format**: `019-02185-0000` (3-5-4 digits)
- **Maricopa format**: `3060735-5`, `897476-8` (variable digits)

### Date Parsing

The `parse_date()` utility supports multiple date formats:
- `DD/MM/YYYY` (European)
- `MM/DD/YYYY` (US)
- ISO 8601 (`YYYY-MM-DD`)
